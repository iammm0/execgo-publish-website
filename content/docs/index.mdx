ExecGo 是面向成熟 Agent 的可靠执行层。它不接管规划与上下文系统，而是把真实动作变成可校验、可取消、可观测、可恢复的任务。

本文档不再围绕 Git 分支组织，而是按产品边界分为三段：生态、ExecGo、runtime。
