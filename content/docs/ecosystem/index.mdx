---
title: 生态总览
description: ExecGo、execgo-runtime 与 Agent 接入的稳定产品模型。
---

ExecGo 生态有两个刻意拆分的运行层：

- **ExecGo** 是控制面。它校验任务、调度依赖图、标准化状态、协调取消，并暴露面向 Agent 的 HTTP 接口。
- **execgo-runtime** 是数据面。它执行进程密集型工作、持久化任务 artifact、上报事件，并负责宿主级资源与沙箱策略。

保持两层分离，可以让 Go 控制面保持轻量、易嵌入，也让 Rust runtime 作为运维型执行服务独立演进、独立发布。
