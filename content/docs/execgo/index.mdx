title: ExecGo control plane
description: The Go control plane for task graphs, mature-agent adapters, executor routing, and normalized action state.
---

ExecGo is the control plane for agent actions. It does not replace an agent's planner or context system. Instead, it turns chosen actions into validated, scheduled, cancellable, observable tasks.

## What ExecGo owns

- Task graph validation and dependency scheduling.
- Retry, timeout, cancellation, and terminal-state semantics.
- Built-in executor categories: `os`, `mcp`, `cli-skills`, and `runtime`.
- Adapter APIs for mature agents such as Codex, Claude Code, Hermes Agent, and OpenClaw.
- State and metrics that let higher layers poll, inspect, and audit actions.

## What ExecGo does not own

- Natural language planning.
- Long-term memory or context-window management.
- The process-level runtime implementation when using `type=runtime`.
- Strong host sandboxing. Use execgo-runtime or your own runtime boundary for that.

Continue with [Quick start](/docs/execgo/quickstart) if you want to run the control plane locally.
