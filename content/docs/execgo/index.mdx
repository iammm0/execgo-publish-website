---
title: ExecGo 控制面
description: 面向任务图、成熟 Agent 适配器、执行器路由与标准化动作状态的 Go 控制面。
---

ExecGo 是 Agent 动作的控制面。它不替代 Agent 的规划器或上下文系统，而是把已经选定的动作变成可校验、可调度、可取消、可观测的任务。

ExecGo 负责任务图校验、依赖调度、重试、超时、取消、适配器 action、执行器路由、状态与指标。它不负责自然语言规划，也不直接承担进程级运行时边界；当执行需要独立数据面时，请使用 [execgo-runtime](/docs/runtime)。
