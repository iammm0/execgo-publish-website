---
title: Runtime integration
description: Configure ExecGo's runtime executor to submit process-heavy work to execgo-runtime.
---

Runtime integration is optional. ExecGo can run without execgo-runtime unless you submit `type=runtime` tasks or use adapter actions such as `runtime.command` and `runtime.script`.

Set the runtime URL in the ExecGo control-plane process:

```bash
export EXECGO_RUNTIME_URL=http://127.0.0.1:8080
```

Submit a runtime task:

```json
{
  "tasks": [
    {
      "id": "build",
      "type": "runtime",
      "params": {
        "execution": {
          "kind": "command",
          "program": "/bin/sh",
          "args": ["-c", "go test ./..."]
        },
        "limits": {
          "wall_time_ms": 120000
        }
      }
    }
  ]
}
```

ExecGo forwards this payload to execgo-runtime, stores the returned handle, polls for terminal state, and normalizes runtime output into the task result envelope.
