---
title: execgo-runtime 数据面
description: 面向进程执行、任务产物、事件与资源感知运维的 Rust 运行时。
---

execgo-runtime 是 ExecGo 的数据面运行时。它作为独立服务运行，接收明确的 HTTP 任务请求，持久化任务元数据与 artifact，并把状态回传给控制面。

runtime 负责显式任务提交、requested/effective execution plan、internal shim 子进程、`request.json`、`result.json`、stdout/stderr 日志、健康检查、就绪检查、指标、事件与能力 API。
