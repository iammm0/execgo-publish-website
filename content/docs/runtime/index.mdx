---
title: execgo-runtime data plane
description: The Rust runtime for process execution, task artifacts, events, and resource-aware operations.
---

execgo-runtime is the data-plane runtime for ExecGo. It runs as a separate service, accepts explicit HTTP task requests, persists task metadata and artifacts, and reports status back to the control plane.

The runtime owns explicit task submission, requested/effective execution plans, internal shim child processes, `request.json`, `result.json`, stdout and stderr logs, health, readiness, metrics, events, and capability APIs.
